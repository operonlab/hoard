# 「システムデータ」とは？

[English](system-data.md) · [繁體中文](system-data.zh-Hant.md) · 日本語 · [한국어](system-data.ko.md)

**システム設定 › 一般 › ストレージ** はディスクをいくつかのカテゴリに分けて表示します。その中の「システムデータ」は大きな割合を占めることが多いのに、中身の一覧はありません。Apple の説明によると、主にシステムが使うファイルやデータ（ログファイル、キャッシュ、VM ファイルなど）で、一時ファイル、フォント、アプリのサポートファイル、プラグインも含まれ、このカテゴリの内容はユーザが管理できません。（[Apple](https://support.apple.com/ja-jp/guide/mac-help/mchl3d437fbc/mac)）

どのファイルをそこに数えたのかをシステム設定は示さないため、このカテゴリを項目ごとに開けるアプリはありません。Hoard もできるふりはしません。Hoard は反対側から数えます。ディスクの使用量から測れるものをすべて引き、残りに名前を付けます。それが「**見えない領域**」のカードです。

## どこで見られるか

1. ディスク全体をスキャンします：**ファイル › ディスク全体「Macintosh HD」をスキャン**（ディスク名は異なる場合があります）。先に Hoard にフルディスクアクセスを許可してください（[インストール](../README.ja.md#インストール) を参照）。許可がないと多くのフォルダを読み取れません。
2. サイドバーで「**クリーンアップ**」を選びます。最初のカードが「見えない領域」です。

コマンドラインでは `hoard hidden` が同じ項目を表示します（プログラムで読むなら `--json` を付けます）。1 つのフォルダだけをスキャンした場合、カードはディスクの残りがスキャンされていないことしか示せません。

## 項目ごとの説明

どのサイズも、測定値、推定値（「約」「〜以上」と表示）、不明のいずれかです。不明なサイズを 0 と表示することはありません。

| 項目 | 内容 | 空けられるか |
|---|---|---|
| **ディスクの総容量**、**空き領域**、**使用済み領域** | ディスク上のすべてのボリュームが共有する APFS コンテナ全体の数字で、ファイルシステムが報告する値です。 | — |
| **スキャン済みファイル** | マップに表示されるすべてのもの。システム設定が「システムデータ」に数えるキャッシュ、ログ、一時ファイル、アプリのサポートファイルは、ここでは `~/Library/Caches` などの普通のフォルダです。 | 一部はできます。「クリーンアップ」は認識できたキャッシュ、ビルド成果物、インストーラ、ログ、削除済みアプリのデータを一覧にし、再生成や再ダウンロードができるものを示します。 |
| **仮想メモリボリューム**（その下に**スワップファイル**と**スリープイメージファイル**） | `/System/Volumes/VM`：メモリが足りないときに macOS が書き出すスワップファイルと、一部の Mac でスリープ用に保持されるイメージです。Apple の説明にある「VM ファイル」がこれです。 | ファイルを削除する方法では空けません。動作中のシステムのものです。必要なメモリが減ると小さくなります。たとえばメモリを多く使うアプリを終了したり、再起動したりしたあとです。 |
| **その他のマウント済みボリューム** | 同じコンテナ内のほかのボリューム。主に macOS 本体を収めた読み取り専用のシステムボリューム（[Apple](https://support.apple.com/ja-jp/guide/security/secd698747c9/web)）と Preboot です。 | できません。macOS の一部です。 |
| **Time Machine のローカルスナップショット** | Time Machine が保持しているローカルスナップショットの数。macOS は一覧を示しますがサイズは示さないため、この項目は数だけを表示します。`tmutil listlocalsnapshots /` でも同じ一覧を確認できます。 | 通常は気にする必要はありません。Time Machine は古くなったスナップショットや、ディスクに空きが必要なときに自動で削除します。早めに消したい場合は、Time Machine の設定で**バックアップの頻度**を**手動**にし、数分待ってから自動バックアップを元に戻します（[Apple](https://support.apple.com/ja-jp/102154)）。 |
| **読み取れないフォルダ** | Hoard に読み取りが許可されなかったフォルダ。サイズは不明です。 | Hoard にフルディスクアクセスを許可して、もう一度スキャンします。 |
| **残りの説明できない領域** | 使用済み領域から、上のサイズのある項目をすべて引いた残り：マウントされていないボリューム（Recovery を含む）、ファイルシステム自身の記録、ほかのアプリが作ったスナップショット、Hoard が読み取れなかったフォルダです。 | まず上の項目を確認してください。読み取れないフォルダがある間や、スナップショットのサイズが不明な間は、この数字は推定値です。 |
| **消去可能な領域** | 必要なときに macOS が自分で空けられる領域：重要なファイルのために macOS が用意する容量（[Apple](https://developer.apple.com/documentation/foundation/urlresourcekey/volumeavailablecapacityforimportantusagekey)）と、単純な空き領域との差です。 | 必要になれば macOS が空けます。 |

## Hoard とシステム設定で数字が違う理由

- **使用済み領域。** Apple によると、Mac はスナップショットが使う領域を空き領域として数えます（[Apple](https://support.apple.com/ja-jp/102154)）。Hoard の使用済み領域はファイルシステムの値なので、その分を使用済みとして数え、「Time Machine のローカルスナップショット」と「消去可能な領域」で説明します。そのため Hoard の使用済み領域は、システム設定の表示より大きくなることがよくあります。
- **カテゴリとフォルダ。** システム設定は各ファイルを 1 つのカテゴリ（アプリケーション、書類、システムデータ…）に入れます。Hoard はフォルダを表示します。システム設定が「システムデータ」に数えるキャッシュは、Hoard のマップではホームフォルダ内の 1 つのフォルダです。
- **共有されたストレージ。** ハードリンクと APFS クローンは、ディスク上の保存のされ方と同じく 1 回だけ数えます。

## Hoard がしないこと

Hoard はシステムファイル、スナップショット、スワップファイルを削除しません。読み取るだけです。スナップショットの数は `tmutil listlocalsnapshots` から得ています。「クリーンアップ」と「ゴミ箱に入れる」が扱うのは Finder でも削除できる項目だけで、必ずあなたの確認を経てから実行します。
