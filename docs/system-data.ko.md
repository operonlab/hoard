# '시스템 데이터'란?

[English](system-data.md) · [繁體中文](system-data.zh-Hant.md) · [日本語](system-data.ja.md) · 한국어

**시스템 설정 › 일반 › 저장 공간**은 디스크를 여러 범주로 나누어 보여 줍니다. 그중 '시스템 데이터'는 큰
비중을 차지할 때가 많지만, 안에 무엇이 있는지는 보여 주지 않습니다. Apple의 설명에 따르면 이 범주에는 주로
시스템이 사용하는 파일과 데이터(로그 파일, 캐시, VM 파일 등)가 들어 있고, 임시 파일, 서체, 앱 지원 파일,
플러그인도 포함되며, 사용자는 이 범주의 내용을 관리할 수 없습니다.
([Apple](https://support.apple.com/ko-kr/guide/mac-help/mchl3d437fbc/mac))

시스템 설정은 어떤 파일을 여기에 넣었는지 알려 주지 않으므로, 이 범주를 항목별로 열어 볼 수 있는 앱은
없습니다. Hoard도 그런 척하지 않습니다. Hoard는 반대쪽에서 계산합니다. 디스크 사용량에서 측정할 수 있는
것을 모두 빼고, 남은 것에 이름을 붙입니다. 그것이 '**보이지 않는 공간**' 카드입니다.

## 어디에서 보나요

1. 디스크 전체를 스캔합니다: **파일 › 전체 디스크 'Macintosh HD' 스캔**(디스크 이름은 다를 수 있습니다).
   먼저 Hoard에 전체 디스크 접근 권한을 주세요([설치](../README.ko.md#설치) 참고). 권한이 없으면 많은
   폴더를 읽을 수 없습니다.
2. 사이드바에서 '**정리**'를 선택합니다. 첫 번째 카드가 '보이지 않는 공간'입니다.

명령줄에서는 `hoard hidden`이 같은 항목을 보여 줍니다(프로그램이 읽을 때는 `--json`을 붙입니다). 폴더
하나만 스캔했다면, 카드는 디스크의 나머지가 스캔되지 않았다는 것만 알려 줄 수 있습니다.

## 항목별 설명

모든 크기는 측정값, 추정값('약' 또는 '최소'로 표시), 알 수 없음 중 하나입니다. 알 수 없는 크기를 0으로
표시하는 일은 없습니다.

| 항목 | 무엇인가 | 비울 수 있나 |
|---|---|---|
| **전체 디스크 용량**, **사용 가능한 공간**, **사용 중인 공간** | 디스크의 모든 볼륨이 함께 쓰는 APFS 컨테이너 전체의 수치로, 파일 시스템이 보고하는 값입니다. | — |
| **스캔한 파일** | 지도에 보이는 모든 것. 시스템 설정이 '시스템 데이터'로 세는 캐시, 로그, 임시 파일, 앱 지원 파일은 여기서 `~/Library/Caches` 같은 평범한 폴더입니다. | 일부는 가능합니다. '정리'는 알아본 캐시, 빌드 산출물, 설치 파일, 로그, 삭제된 앱의 데이터를 보여 주고, 다시 만들거나 다시 내려받을 수 있는 것을 표시합니다. |
| **가상 메모리 볼륨**(아래에 **스왑 파일**과 **잠자기 이미지 파일**) | `/System/Volumes/VM`: 메모리가 부족할 때 macOS가 쓰는 스왑 파일과, 일부 Mac이 잠자기를 위해 두는 이미지입니다. Apple 설명의 'VM 파일'이 이것입니다. | 파일을 지우는 방식으로는 안 됩니다. 실행 중인 시스템의 것입니다. 필요한 메모리가 줄면 작아집니다. 예를 들어 메모리를 많이 쓰는 앱을 종료하거나 재시동한 뒤입니다. |
| **기타 마운트된 볼륨** | 같은 컨테이너의 다른 볼륨들. 주로 macOS 자체를 담은 읽기 전용 시스템 볼륨([Apple](https://support.apple.com/ko-kr/guide/security/secd698747c9/web))과 Preboot입니다. | 안 됩니다. macOS의 일부입니다. |
| **Time Machine 로컬 스냅샷** | Time Machine이 보관 중인 로컬 스냅샷의 개수. macOS는 목록은 보여 주지만 크기는 알려 주지 않으므로 이 항목은 개수만 표시합니다. `tmutil listlocalsnapshots /`로도 같은 목록을 볼 수 있습니다. | 보통은 신경 쓸 필요가 없습니다. Time Machine은 오래된 스냅샷이나 디스크 공간이 필요할 때 자동으로 지웁니다. 더 빨리 지우려면 Time Machine 설정에서 **백업 빈도**를 **수동으로**로 바꾸고 몇 분 기다린 뒤 자동 백업을 다시 켭니다([Apple](https://support.apple.com/ko-kr/102154)). |
| **읽을 수 없는 폴더** | Hoard가 끝까지 읽지 못한 폴더. 대부분 읽기 권한이 없어서입니다. 크기는 알 수 없습니다. | Hoard에 전체 디스크 접근 권한을 주고 다시 스캔합니다. |
| **나머지 설명할 수 없는 공간** | 사용 중인 공간에서 위의 크기가 있는 항목을 모두 뺀 나머지: 마운트되지 않은 볼륨(Recovery 포함), 파일 시스템 자체의 기록, 스냅샷만 차지하고 있는 공간(Time Machine과 다른 앱의 스냅샷 모두), Hoard가 읽지 못한 폴더입니다. | 먼저 위 항목들을 확인하세요. 읽을 수 없는 폴더가 있거나 스냅샷 크기를 모르는 동안에는 이 수치는 추정값입니다. |
| **제거 가능한 공간** | 필요할 때 macOS가 스스로 비울 수 있는 공간: macOS가 중요한 파일을 위해 내주는 용량([Apple](https://developer.apple.com/documentation/foundation/urlresourcekey/volumeavailablecapacityforimportantusagekey))과 단순한 사용 가능 공간의 차이입니다. | 필요하면 macOS가 비웁니다. |

## Hoard와 시스템 설정의 수치가 다른 이유

- **사용 중인 공간.** Apple에 따르면 Mac은 스냅샷이 쓰는 공간을 사용 가능한 공간으로 셉니다
  ([Apple](https://support.apple.com/ko-kr/102154)). Hoard의 사용 중인 공간은 파일 시스템의 값이라 그만큼을
  사용 중으로 셉니다. macOS는 스냅샷 크기를 알려 주지 않으므로, 스냅샷만 차지하고 있는 공간은 어느 폴더에도
  속하지 않고 '나머지 설명할 수 없는 공간'에 들어갑니다. 그래서 Hoard의 사용 중인 공간은 시스템 설정에 보이는
  값보다 클 때가 많습니다.
- **범주와 폴더.** 시스템 설정은 각 파일을 하나의 범주(응용 프로그램, 문서, 시스템 데이터 등)에 넣습니다.
  Hoard는 폴더를 보여 줍니다. 시스템 설정이 '시스템 데이터'로 세는 캐시는 Hoard 지도에서 홈 폴더 안의 폴더
  하나입니다.
- **공유된 저장 공간.** 하드 링크와 APFS 클론은 디스크에 저장된 방식대로 한 번만 계산합니다.

## Hoard가 하지 않는 일

Hoard는 시스템 파일, 스냅샷, 스왑 파일을 지우지 않습니다. 읽기만 합니다. 스냅샷 개수는
`tmutil listlocalsnapshots`에서 가져옵니다. '정리'와 '휴지통으로 이동'은 Finder에서도 지울 수 있는 항목만
다루며, 반드시 당신이 확인한 뒤에 실행합니다.
